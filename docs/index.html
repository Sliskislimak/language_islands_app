OVERVIEW

SideStore（サイドストア）とは？ なぜ必要なの？

Appleの公式App Storeは、年間約15,000円の開発者登録費や審査が必要です。個人間のプライベートアプリをiPhoneに入れるため、Apple公式の仕組みを利用した「サイドローディング（SideStore）」を使用します。

🛡️
安全性について安心してください
脱獄（Jailbreak）ではありません。Appleが公式に提供している個人デベロッパ証明書を使って、あなたのiPhoneだけに直接署名してインストールする完全合法かつ安全な方法です。
📶
PC不要でワイヤレス更新
最初の1回だけPCを使えば、以後はiPhone内のLocalDevVPNを使ってどこでもワイヤレス更新できます（iTunesやiCloudのインストールも一切不要です！）。
STEP 1

SideStoreの初期セットアップ（最初の1回のみ）

初回のみ、パソコン（Windows または Mac）を使ってSideStoreをiPhoneに転送します。iTunesやiCloudは不要で、約10分で完了します。

準備するもの

  • 📱 お使いのiPhone（iOS 14以降、iOS 16/17/18対応）
  • 💻 パソコン（Windows または Mac）※初回1回のみ使用（iTunes/iCloudは不要！）
  • 🔌 iPhoneとPCを繋ぐUSBケーブル
  • 🆔 Apple ID（普段お使いのものでOK）
1
iPhoneに「LocalDevVPN」をインストール（App Store）

SideStoreがiPhone単体でアプリをワイヤレス更新できるように、App Store公式の「LocalDevVPN」を使用します。設定ファイルのダウンロードは不要です！

App StoreでLocalDevVPNを入手 ↗
💡
インストール後、LocalDevVPNを開いて「Connect」をタップし、iOSのVPN構成追加ポップアップで「許可」を選択してパスコードを入力します。
2
iPhoneの「デベロッパモード」をONにする（iOS 16以降）

iOS 16、17、18をお使いの場合、外部アプリの起動を許可するモードを有効にします。

⚙️ 設定 → プライバシーとセキュリティ → デベロッパモード

スイッチをONにするとiPhoneの再起動を求められます。再起動後に「オンにする」をタップし、パスコードを入力すれば完了です。

3
パソコンで「iloader」を使ってSideStoreを導入

1. iloader (Windows版 .msi) をダウンロードしてインストールします（iTunesやiCloudのインストールは一切不要です！）。

2. iPhoneをUSBケーブルでPCに接続し、iPhone画面で「このコンピュータを信頼する」をタップします。

3. iloaderを起動し、お使いのApple IDでサインインします（※メールアドレスの大文字・小文字は正確に入力してください）。

4. 接続されたiPhoneを選択し、「Install SideStore (Stable)」をクリックします。自動的にSideStoreがiPhoneに転送されます！

iloader for Windows (.msi) を入手 ↗

1. iloader (macOS版 .dmg) をダウンロードし、「アプリケーション」フォルダへ移動して起動します（iTunes/iCloud不要）。

2. iPhoneをケーブルでMacに接続し、FinderまたはiPhone画面で「信頼」をタップします。

3. iloaderでお使いのApple IDでサインインします（※メールアドレスは大文字・小文字を区別します）。

4. 接続されたiPhoneを選択し、「Install SideStore (Stable)」をクリックします。

iloader for macOS (.dmg) を入手 ↗
4
iPhoneでデベロッパアプリを「信頼」する

インストールが完了したら、iPhoneの設定で起動を許可します。

⚙️ 設定 → 一般 → VPNとデバイス管理 → あなたのApple ID

「（Apple ID）を信頼」をタップして確認を押します。これでSideStoreが起動できるようになります！

5
SideStoreの初期起動＆セットアップ完了

LocalDevVPNを開いて「Connect」をタップした状態で、SideStoreを開きます。Apple IDでサインインし、「My Apps」画面の「7 DAYS」カウンターをタップして初回の更新を完了させます。

STEP 2

アプリ（Language Islands）をiPhoneにインストール

SideStoreの準備ができたら、いよいよアプリ本体（Runner.ipa）をインストールします。

Runner.ipa (最新版アプリ) をダウンロード ↓ 📦 バージョン一覧・詳細はこちら ↗

※ iPhoneのSafariでダウンロードしてください（iOS 14.0〜18.x対応）

1. iPhoneのSafariで上記の「Runner.ipa をダウンロード」ボタンをタップします。

2. LocalDevVPN アプリを開き、接続中（Connected / 画面上のVPNアイコン）になっていることを確認します。

3. SideStore を開き、下の「My Apps」タブを表示します。

4. 左上の 「＋」 アイコンをタップし、先ほどダウンロードした Runner.ipa を選択します。

5. インストールが進行し、完了するとiPhoneのホーム画面に Language Islands のアイコンが追加されます！🎉

💡
💡 週に1回のリフレッシュについて（5秒で完了）
無料のApple IDで入れたアプリは7日間の有効期限があります。期限が切れる前に、iPhoneで「LocalDevVPNをON」にし、「SideStoreを開いて Refresh All を押す」だけで自動延長されます（PCはもう不要です！）。
STEP 3

アプリで「ポーランド語学習」を設定する

アプリを起動したら、あなたがポーランド語を学べるように学習言語（Target Language）を設定します。

1. iPhoneのホーム画面から Language Islands をタップして開きます。

2. 画面右上にある 3つの点メニュー「︙」 をタップします。

3. メニューから 「Język nauki (docelowy)」(学習言語の選択) をタップします。

4. 一覧から 「🇵🇱 Polski (Marek / Zofia - Polish Neural)」 を選択します。

5. これでターゲット言語がポーランド語に切り替わります！

どうやって勉強するの？

🎧 シャドーイング（Shadowing）モード

ポーランド語の音声が流れます。耳で聴きながら声に出して真似しましょう。文の下に カタカナ読み補助（例: 「チェシチ！ヤク シェ マシュ？」）が表示されるので、難しい発音も一目でわかります！

🧠 アクティブリコール（Active Recall）モード

日本語の意味が表示されます。それを声に出してポーランド語で言ってみてください。カードをタップするとポーランド語の正解とネイティブ音声が再生され、1〜5つ星で自己評価できます。

STEP 4

文の共有・送受信設定（Gistでつながる）

あなたとJakubのアプリをGitHub Gistで連携させます。これであなたが送った日本語がJakubのアプリに届き、Jakubが作ったポーランド語があなたのアプリに届きます！

1. 共有データベース（Gist）の接続・受信設定

1. アプリ右上の 「︙」 メニューをタップします。

2. 「Zdalna baza zdań / Synchronizacja」（雲の同期アイコン）をタップします。

3. 「Adres URL bazy danych / JSON」 の入力欄を設定します：

✨
【最速・ワンタップ入力】
URL入力欄のすぐ下にある紫色のボタン ✨ Wstaw domyślny wspólny Gist (Jakub & Przyjaciółka) をタップするだけで、共有Gistのアドレスが一瞬で自動入力されます！

または、以下の共有URLをコピーして直接貼り付けることもできます：

https://gist.github.com/Sliskislimak/8d8efa2b1884930a0894553eec419283
💡
【Klucz API / Token autoryzacji 欄について】
Jakubからのレッスンを受信・閲覧・同期するだけなら、この欄は 【空欄（空っぽ）】 のままで大丈夫です！（パスワード不要で誰でもダウンロードできます）

4. 「起動時に自動同期」（Auto-sync on startup）のスイッチをONにします。

5. 「今すぐ同期」（Synchronizuj teraz）をタップします。これでJakubが作ったポーランド語レッスンが一気に届きます！🎉

2. こはるちゃんからJakubへ「日本語フレーズ」を送る方法

Jakubに勉強してほしい日常会話や好きな表現をいつでも送れます！

1. 画面右下のピンクのハートボタン 「＋」 または右上のメニュー「︙」から 「Dla Jakuba / Jakubへフレーズを送る」 をタップします。

2. 上部の切替タブが 「🇯🇵 日本語 (Dla Jakuba)」 になっていることを確認します。

3. 以下の項目を入力します：

• 1. 日本語（漢字・ひらがな）：例「これ、すごく美味しいよ！」 • 2. カタカナ読み：例「コレ、スゴク オイシイ ヨ！」 • 3. ローマ字 (Rōmaji)：例「Kore, sugoku oishii yo!」 • 4. 意味・メモ (Znaczenie)：例「To jest naprawdę pyszne! / This is so delicious!」 • 5. メモ・使い方 (任意)：例「食事の時に使うカジュアルな表現」
🔑
【初回のみ】フレーズ送信の接続設定（GitHub Token）
Gistへ新しい文を追加（送信）するには書き込み権限が必要です。フォーム内の「GitHub Gist設定 (Prywatne połączenie)」を開き：
・Gist URL: 共通Gistアドレスを自動入力 をタップ
・GitHub Token: Jakubから受け取った専用のGitHubトークン（PAT）を入力して「設定を保存」します。

4. 画面下の 「送信 & 保存 (Wyślij do GitHuba i Zapisz)」 ボタンをタップします！

🌸
これだけで共有データベースに送信され、Jakubがアプリを開いたときに自動的にこはるちゃんの日本語フレーズが学習リストに加わります！🌸

TROUBLESHOOTING

よくある質問・トラブルシューティング

LocalDevVPNアプリを開き、VPNが接続中（Connected / 画面上にVPNアイコン表示）になっていることを確認してください。VPNが切れているとSideStoreは動作しません。
iPhoneの「設定」→「一般」→「VPNとデバイス管理」を開き、あなたのApple IDをタップして「信頼」を押してください。
iPhone本体の左側面にある着信/消音スイッチ（マナーモード）が消音（オレンジ色）になっていないか、音量がゼロになっていないか確認してください。
消えません！学習データや送った文もすべてiPhone内に安全に残ります。LocalDevVPNをONにしてSideStoreで「Refresh All」を押せば、いつでもすぐに復活します。
新しい「Runner.ipa」をダウンロードし、SideStoreの「＋」ボタンから追加で読み込むだけです。これまでのデータは消えずにそのままアップデートされます。
