OVERVIEW

SideStore（サイドストア）とは？ なぜ必要なの？

Appleの公式App Storeは、年間約15,000円の開発者登録費や審査が必要です。個人間のプライベートアプリをiPhoneに入れるため、Apple公式の仕組みを利用した「サイドローディング（SideStore）」を使用します。

🛡️
安全性について安心してください
脱獄（Jailbreak）ではありません。Appleが公式に提供している個人デベロッパ証明書を使って、あなたのiPhoneだけに直接署名してインストールする完全合法かつ安全な方法です。
📶
PC不要で更新可能
従来のAltStoreと違い、最初の1回だけPCを使えば、以後はiPhone内のWireGuard VPNを使ってどこでもワイヤレス更新できます。
STEP 1

SideStoreの初期セットアップ（最初の1回のみ）

初回のみ、パソコン（Windows または Mac）を使ってSideStoreをiPhoneに転送します。約10〜15分で完了します。

準備するもの

  • 📱 お使いのiPhone（iOS 14以降、iOS 16/17/18対応）
  • 💻 パソコン（Windows または Mac）※初回1回のみ使用
  • 🔌 iPhoneとPCを繋ぐUSBケーブル
  • 🆔 Apple ID（普段お使いのものでOK）
1
iPhoneでWireGuardをインストール＆設定

SideStoreがiPhone単体でアプリを更新できるように、仮想VPN「WireGuard」を使用します。

App StoreでWireGuardを入手 ↗ SideStore.conf をダウンロード ↓
💡
ダウンロード後、WireGuardアプリを開き「トンネルの追加」→「ファイルからインポート」で「SideStore.conf」を選択して有効化（緑色のON）にしてください。
2
iPhoneの「デベロッパモード」をONにする（iOS 16以降）

iOS 16、17、18をお使いの場合、外部アプリの起動を許可するモードを有効にします。

⚙️ 設定 → プライバシーとセキュリティ → デベロッパモード

スイッチをONにするとiPhoneの再起動を求められます。再起動後に「オンにする」をタップし、パスコードを入力すれば完了です。

3
パソコンでのSideServerインストール

1. Apple公式サイトから iTunes と iCloud（※Microsoft Store版ではなく、必ずスタンドアロン版）をインストールします。

2. SideServer for Windows をダウンロードして解凍し、起動します。

3. iPhoneをUSBケーブルでPCに接続し、iPhone画面で「このコンピュータを信頼する」をタップします。

4. タスクバー右下のSideServerアイコンをクリックし、「Install SideStore」からお使いのiPhoneを選択し、Apple IDとパスワードを入力します。

SideServer for Windows を入手 ↗

1. SideServer for macOS をダウンロードし、「アプリケーション」フォルダへ移動します。

2. SideServerを起動し、メニューバーのアイコンをクリックします。

3. iPhoneをケーブルでMacに接続し、Finderで「信頼」をクリックします。

4. SideServerメニューから「Install SideStore」を選択し、Apple IDを入力します。

SideServer for macOS を入手 ↗
4
iPhoneでデベロッパアプリを「信頼」する

インストールが完了したら、iPhoneの設定で起動を許可します。

⚙️ 設定 → 一般 → VPNとデバイス管理 → あなたのApple ID

「（Apple ID）を信頼」をタップして確認を押します。これでSideStoreが起動できるようになります！

5
SideStoreの初期起動＆ペアリングファイル

WireGuardでVPNをON（有効）にした状態でSideStoreを開きます。画面の指示に従ってペアリングファイルを選択し、Apple IDでサインインします。

STEP 2

アプリ（Language Islands）をiPhoneにインストール

SideStoreの準備ができたら、いよいよアプリ本体（Runner.ipa）をインストールします。

Runner.ipa (最新版アプリ) をダウンロード ↓

※ iPhoneのSafariでダウンロードしてください

1. iPhoneのSafariで上記の「Runner.ipa をダウンロード」ボタンをタップします。

2. WireGuard アプリを開き、VPNが ON（有効） になっていることを確認します。

3. SideStore を開き、下の「My Apps」タブを表示します。

4. 左上の 「＋」 アイコンをタップし、先ほどダウンロードした Runner.ipa を選択します。

5. インストールが進行し、完了するとiPhoneのホーム画面に Language Islands のアイコンが追加されます！🎉

💡
💡 週に1回のリフレッシュについて（5秒で完了）
無料のApple IDで入れたアプリは7日間の有効期限があります。期限が切れる前に、iPhoneで「WireGuardのVPNをON」にし、「SideStoreを開いて Refresh All を押す」だけで自動延長されます（PCはもう不要です！）。
STEP 3

アプリで「ポーランド語学習」を設定する

アプリを起動したら、あなたがポーランド語を学べるように学習言語（Target Language）を設定します。

1. iPhoneのホーム画面から Language Islands をタップして開きます。

2. 画面右上にある 3つの点メニュー「︙」 をタップします。

3. メニューから 「Język nauki (docelowy)」(学習言語の選択) をタップします。

4. 一覧から 「🇵🇱 Polski (Marek / Zofia - Polish Neural)」 を選択します。

5. これでターゲット言語がポーランド語に切り替わります！

どうやって勉強するの？

🎧 シャドーイング（Shadowing）モード

ポーランド語の音声が流れます。耳で聴きながら声に出して真似しましょう。文の下に カタカナ読み補助（例: 「チェシチ！ヤク シェ マシュ？」）が表示されるので、難しい発音も一目でわかります！

🧠 アクティブリコール（Active Recall）モード

日本語の意味が表示されます。それを声に出してポーランド語で言ってみてください。カードをタップするとポーランド語の正解とネイティブ音声が再生され、1〜5つ星で自己評価できます。

STEP 4

文の共有・送受信設定（Gistでつながる）

あなたとJakubのアプリをGitHub Gistで連携させます。これであなたが送った日本語がJakubのアプリに届き、Jakubが作ったポーランド語があなたのアプリに届きます！

1. 共有データベース（Gist）の接続

1. アプリ右上の 「︙」 メニューをタップします。

2. 「Zdalna baza zdań / Synchronizacja」（雲の同期アイコン）をタップします。

3. 以下の「共有URL」をコピーして、入力欄に貼り付けます。

https://api.github.com/gists/SHARED_GIST_ID

4. 「起動時に自動同期」（Auto-sync on startup）のスイッチをONにします。

5. 「今すぐ同期」（Synchronizuj teraz）をタップします。これでJakubが作ったポーランド語レッスンが一気に届きます！

2. あなたからJakubへ「日本語フレーズ」を送る方法

Jakubに勉強してほしい日常会話や好きな表現をいつでも送れます！

1. アプリ上部の 紙飛行機 / ハートアイコン またはメニュー「︙」から 「Dla Przyjaciela / Wyślij zwrot」 をタップします。

2. 上部の切替タブが 「日本語 (Dla Jakuba / 友だちへ)」 になっていることを確認します。

3. 以下の4項目を入力します：

• 1. 日本語（漢字・ひらがな）：例「これ、すごく美味しいよ！」 • 2. カタカナ読み：例「コレ、スゴク オイシイ ヨ！」 • 3. ローマ字：例「Kore, sugoku oishii yo!」 • 4. 意味・メモ：例「To jest naprawdę pyszne!」やシチュエーション

4. 「送信 / 送る」 ボタンをタップします！

🌸
これだけで共有データベースに送信され、Jakubがアプリを開いたときに自動的にあなたの日本語フレーズが学習リストに加わります！🌸

TROUBLESHOOTING

よくある質問・トラブルシューティング

WireGuardアプリを開き、VPNが有効（緑色のスイッチON）になっていることを確認してください。VPNが切れているとSideStoreは動作しません。
iPhoneの「設定」→「一般」→「VPNとデバイス管理」を開き、あなたのApple IDをタップして「信頼」を押してください。
iPhone本体の左側面にある着信/消音スイッチ（マナーモード）が消音（オレンジ色）になっていないか、音量がゼロになっていないか確認してください。
消えません！学習データや送った文もすべてiPhone内に安全に残ります。WireGuardをONにしてSideStoreで「Refresh All」を押せば、いつでもすぐに復活します。
新しい「Runner.ipa」をダウンロードし、SideStoreの「＋」ボタンから追加で読み込むだけです。これまでのデータは消えずにそのままアップデートされます。
